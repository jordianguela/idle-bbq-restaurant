# Graella (model 3D)

Model 3D d'una graella (Blender 4.0 + FBX + OBJ) amb la seva paleta de gradients.

**No es fa servir al joc**: el nivell 1 es dibuixa amb sprites 2D de 16 px i això
és geometria 3D. Per aprofitar-lo caldria renderitzar-lo des de Blender a imatges
(una per estat: apagada, encesa, amb carn) i afegir-les com un sprite més.
